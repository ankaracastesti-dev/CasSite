# Psk. Dan. Samet Ağcaer – CAS Testi Ankara

Tek sayfalık tanıtım sitesi. Sadece HTML, CSS ve biraz JavaScript kullanır; kurulum gerekmez.

## Dosyalar

| Dosya | Ne işe yarar |
|---|---|
| `index.html` | Sayfanın içeriği (metinler, bölümler, bağlantılar) |
| `style.css` | Görünüm (renkler, yazı tipleri, telefon uyumu) |
| `script.js` | Telefon menüsü, "CAS testi neye bakar?" sekmeleri, alttaki WhatsApp düğmesi |
| `favicon.svg` | Tarayıcı sekmesindeki küçük ikon |
| `images/` | Portre fotoğrafı buraya konacak |

## Sık yapılacak değişiklikler

- **Metin değiştirmek:** `index.html` dosyasında yazıyı bulun ve değiştirin.
- **Portre fotoğrafı eklemek:** `images/BENI-OKU.txt` dosyasına bakın.
- **Renk değiştirmek:** `style.css` dosyasının en üstündeki `:root` bloğu.
- **Hakkımda yazısı:** `index.html` içinde "HAKKIMDA" bölümündeki paragraflar.

## Bilgisayarda görmek

`index.html` dosyasına çift tıklamanız yeterli.
